## Quy tắc làm việc và Triển khai (Working Protocol)

1.  **Single Source of Truth (SSOT):** Luôn cập nhật `MASTER_SPECIFICATION.md` khi có thay đổi về tính năng, DB hay UI. Mọi phiên làm việc phải bắt đầu bằng việc đọc tài liệu này.
2.  **Database Mastery:** Toàn bộ lệnh SQL phải được lưu trữ tập trung tại `DATABASE.md`. Không được thực thi lệnh SQL mà không ghi lại vào file này.
3.  **100% Fullstack Rule:** Khi báo cáo hoàn thành một tác vụ, yêu cầu phải xong cả Backend (DB/Logic) và Frontend (UI/UX). Code phải chạy được và không có lỗi.
4.  **Skill-Driven Development:** Phải kiểm tra và sử dụng các Skill trong thư mục để đảm bảo chất lượng code (Next.js Best Practices, Supabase Master, Clean Code).
5.  **Progress Transparency:** Cập nhật trạng thái `[x]` vào `ROADMAP.md` và tạo báo cáo tiến độ tại `PROGRESS_REPORT.md` sau mỗi mốc quan trọng.
